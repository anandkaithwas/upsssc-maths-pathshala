# UPSSSC Maths Pathshala

Mobile-first educational platform for UPSSSC, SSC, UP Police and Railway aspirants.

## Frontend starter
React + Vite, responsive Hindi-first interface, subject cards, sample interactive quiz, searchable study resources and social links.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Deploy to Cloudflare Pages with build command `npm run build` and output directory `dist`.

## Current scope
This initial release is a frontend foundation. Paid checkout, secure premium downloads, student authentication, admin publishing and production mock-test persistence must be implemented before accepting payments. Never place secret keys or paid PDFs in public frontend assets.

## Free-tier note
Cloudflare/GitHub free plans have quotas and terms. Domain registration, payment processing and some third-party services may cost money.
